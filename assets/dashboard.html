      카메라

      카메라 찾기·추가·수정·삭제·연결 테스트와 IP로 찾기는 Capture VMS Viewer의 [설정] → 카메라에서 합니다. 연결 문제는 뷰어의 [문제 진단]으로 확인하세요.

      트리거 (동시 촬영 신호)

      신호 1번에 '트리거 대상' 카메라를 모두 같은 순간에 찍습니다. 대시보드 [동시 촬영]·스페이스바는 항상 되고, PLC는 아래 방식 중 현장에 맞는 것을 켜세요.

      공통

      앞 신호 뒤 이 시간 안에 또 온 신호는 찍지 않고 '무시'로만 기록합니다 (접점 채터링·중복 신호). 수신 중인 카메라는 받고 있는 영상에서 바로 찍고(약 0.2초), 수신 안 하는 카메라는 그때 접속해서 찍습니다(약 1초).

      PLC → TCP 메시지 (이 PC가 받음)

      PLC가 이 PC의 IP·포트로 TCP 연결해 메시지를 보내면 1줄(줄바꿈·NUL 또는 50ms 쉼)마다 1번 찍습니다. 응답: OK,번호,전체ms,편차ms / NG,… / IGNORED,…. 처음 켤 때 Windows 방화벽 허용 창이 뜨면 '허용'을 누르세요.

      Modbus TCP (이 PC가 PLC를 읽음)

      정한 주소의 값이 0 → 1(0이 아닌 값)로 바뀌는 순간 1번 찍습니다. 결과 레지스터를 정하면 촬영 뒤 1(성공)/2(실패)를 씁니다 (FC6). PLC 문서가 00001·40001처럼 1부터 세면 1을 빼고 넣으세요.

      저장 위치 · 녹화 파일

      새로 시작하는 세션부터 적용됩니다. 기존 녹화·로그는 옮기지 않고 원래 폴더에 둡니다.

      일
      이보다 오래된 녹화·로그는 자동으로 지웁니다 · 0이면 지우지 않습니다. 메인 스트림 녹화는 1시간에 약 3GB입니다.
      분
      녹화를 이 길이마다 새 파일로 나눕니다 (1~60분). 짧을수록 프로그램이 갑자기 꺼졌을 때 잃는 부분이 적고, 원하는 순간의 파일을 찾기 쉽습니다. 전체 용량은 같습니다.
